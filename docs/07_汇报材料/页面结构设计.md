# 三页 PPT 页面结构

依据已确认的《PPT提纲.md》和本轮提供的设计规范。当前只确定版式、图示和要点位置。

## 统一版式

- 画布：16:9，13.333 × 7.5 英寸，纯白底 #FFFFFF。
- 字体：Times New Roman。中文排版需补足该字体缺少的字形，最终检查中文显示与换行。
- 页标题：25 pt、加粗、黑色，左对齐。三页均为内容页。
- 栏目标题：19.5 pt、加粗、#3B78C3。
- 图内文字与右栏要点：16 pt、黑色。必要的次级标题18 pt、加粗、#3B78C3。
- 页底结论：17 pt、加粗、#111111。
- 分隔线：0.5 pt、#CFCFCF。
- 图示使用简单直角矩形、线条、箭头与时间线，保持无填充或白色填充；同一逻辑层级保持相同线宽。
- 红色 #D9272E 仅用于具体证据的1.2–1.5 pt无填充轮廓。本轮结构图采用黑、蓝、灰。
- 页脚左侧7 pt、灰色，显示“勇攀高峰 · Web Agent 系统设计”；右侧10 pt页码。
- 图示索引如需使用，放在蓝色栏目标题处。来源按实际项目文件或所引论文填写。

## 第1页：整体架构

**核心：同一决策循环适配两种环境。**

| 位置 | 内容 |
| --- | --- |
| 左栏标题 | 双环境执行架构 |
| 右栏标题 | 关键设计 |
| 左栏图示 | 任务输入、EffGen、统一工具、两个执行后端，以及观察返回路径 |
| 右栏第1组 | 分工：EffGen规划决策；程序执行与校验 |
| 右栏第2组 | 接口：统一动作与观察；后端转换协议 |
| 右栏第3组 | 循环：网页动作处暂停；新观察到达后继续 |
| 页底结论 | 同一执行循环，连接官方平台与真实浏览器 |

### 图示安排

- 图的左侧放“任务输入”，中间放“EffGen / Qwen3.6-35B-A3B”和“统一网页工具”。
- 图的右侧上下排列“官方 SDK”和“Playwright”，分别连接“官方环境”和“真实浏览器”。
- 动作路径从左向右；观察路径从下方返回EffGen，以箭头和“新观察”标注。
- “任务状态与证据”放在EffGen下方，与决策循环连接。
- 只标模块和关系，工具列表与实现文件名留在讲述中。

## 第2页：任务执行与容错

**核心：依据证据确认进度，出错后保留有效状态。**

| 位置 | 内容 |
| --- | --- |
| 左栏标题 | 执行与核验流程 |
| 右栏标题 | 执行约束 |
| 左栏图示 | 目标、动作、页面反馈、条件核验和账本更新；失败返回继续纠正 |
| 右栏第1组 | 状态：目标、事实、进度、证据 |
| 右栏第2组 | 接管：全局暂停；刷新观察后继续 |
| 右栏第3组 | 并行：独立只读并行；共享写入串行；统一限流与预算 |
| 页底结论 | 根据核验结果更新进度，恢复时保留无关的已确认状态 |

### 图示安排

- 主流程采用两行排列，避免过长：第一行“当前目标”“执行动作”“页面反馈”，第二行“条件核验”“更新进度”。
- 条件核验分为“通过”“失败”“未知”：通过进入进度更新，失败回到继续纠正，未知进入取证后再核验。
- “任务账本”作为图底部共享状态，与当前目标、核验及进度更新连接。
- 通过箭头位置区分正常执行和纠正路径；使用黑色主线、蓝色核验标签和灰色辅助线。
- 右栏三组要点与左图上下对齐；人工接管和并行采用文字说明。

## 第3页：开发与验证逻辑

**核心：分阶段实现，依据运行证据选择设计。**

| 位置 | 内容 |
| --- | --- |
| 左栏标题 | 三阶段开发路线 |
| 右栏标题 | 开发与验证方法 |
| 左栏图示 | 三阶段纵向时间线；阶段末尾回到问题定位与下一轮修改 |
| 右栏第1组 | 依据：赛题约束、框架复用、论文候选 |
| 右栏第2组 | 实现：接口与验收条件；DSH开发、主线程集成 |
| 右栏第3组 | 迭代：轨迹定位、最小修改、单变量比较、保留任务回归 |
| 页底结论 | 先跑通、再补能力，通过实验确定最终配置 |

### 图示安排

- 左栏使用一条纵向时间线，排列三个阶段，阶段编号用普通文字。
- 阶段1“双环境跑通”：模型、浏览器、官方平台。
- 阶段2“基础能力与测试环境”：状态、核验恢复、接管与并行。
- 阶段3“实验验证”：固定条件、逐项比较、回归检查。
- 时间线下方用短箭头连接“运行证据”“问题定位”“最小修改”，形成后续迭代关系。
- 阶段标签说明开发顺序，不以颜色或勾选符号暗示全部完成。
