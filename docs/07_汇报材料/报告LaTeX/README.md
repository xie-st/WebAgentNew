# Web Agent方案报告

主文件：`main.tex`。矢量图与伪代码直接写在LaTeX源文件中，无外部图片依赖。

使用本机MiKTeX XeLaTeX编译，中文字体为宋体、黑体及微软雅黑，英文字体为Times New Roman，等宽字体为Consolas。在PowerShell运行：

```powershell
& .\build.ps1
```

脚本连续编译两次以解析引用和总页数，PDF保存到同级“成品”目录，辅助文件保存在本项目`build/`中。

本版基于审定的Markdown稿，包含开发链路、双环境执行、只读并行调度三幅TikZ矢量图，以及可暂停循环伪代码；第三阶段、实验结果和最终设计正文留空。

按用户要求采用舒展的单栏学术论文版式：题名与作者居中，包含摘要和关键词，正文行距1.22、段距3pt；深蓝标题、浅蓝图表底色及少量青绿色分组。三线表和算法统一编号，章节与图表周围适当留白。

交付PDF共4页，已通过本机编译、引用检查、字体嵌入检查和逐页渲染检查，核验摘要保存在`validation.json`。
