# Web Agent 系统设计与开发逻辑

## 第1页：整体架构

- 决策与执行分工：EffGen规划决策，程序执行与校验。
- 双环境适配：统一网页工具，连接官方平台与真实浏览器。
- 可暂停循环：交出网页动作，接收新观察后继续。

## 第2页：任务执行与容错

- 任务账本：目标、事实、进度与证据。
- 核验恢复：检查结果、纠正错误、保留有效进度。
- 人工接管：全局暂停，重新观察后继续。
- 受控并行：独立只读任务并行，共享写入串行，统一限流与预算。

## 第3页：开发与验证逻辑

- 设计依据：赛题约束、框架复用、论文方法候选。
- 三阶段：双环境跑通、基础能力与测试环境、实验验证。
- 开发分工：明确接口与验收条件，DSH实现，主线程集成验证。
- 迭代方法：轨迹定位、最小修改、单变量比较、保留任务回归。
