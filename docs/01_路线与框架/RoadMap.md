# 整体方向

让 EffGen 拥有完整的观察—思考—工具执行—反馈循环，并持续负责规划、核验与恢复。外围代码负责连接环境、保存事实、检查协议和记录日志。

通过技术让 EffGen 能够直接转化到测评环境里，并保持在真实环境中的优化结果。

## 转换方式

把 Agent 循环写成一个 Python 生成器：循环体内每次需要新观察就 yield 动作，step() 被调用时 gen.send(观察) 让它原地继续。（如果不好的话可以讨论）

这种转换方式不支持并行处理，但是因为评测器中的任务都是单线程的，所以没有关系。另外迁移时需要不启用相关内容。
