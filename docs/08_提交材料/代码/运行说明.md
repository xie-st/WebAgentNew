# 迁入工程：运行与后续补丁

迁入日期：2026-10-31。**本目录为后续补丁、运行及交付核验的工作位置。** 原主树作为迁入来源保留；此后修改本目录的 `code/` 和配置，不再用旧主树覆盖本目录。

本目录保留完整 `code/harness`、`code/vendor/effgen` 和 `code/official_client`。demo 素材、静态资源和回归测试一并迁入。初始来源与文件哈希见 `delivery-manifest.json`；迁入后的修正及最终哈希见 `迁移验证.json`。

从本目录执行：

```powershell
.\install.ps1
.\start-demo.ps1
.\start-official.ps1 -ConnectionFile '<本队连接文件绝对路径>'
```

安装需要 Python 3.12、uv、包源及 Chromium 下载资源；已建环境可直接启动。demo 默认地址 `http://127.0.0.1:8787`，端口可用 `-Port` 修改。后续移到其他机器或目录后重新执行安装，重建 editable 导入路径。

真实端配置为 `code/harness/configs/real.yaml`，模型名已合并原主树本机配置中的 `qwen3.6-35b-a3b`。在启动 demo 的终端设置 `WEBAGENT_MODEL_BASE_URL` 和 `WEBAGENT_MODEL_API_KEY`。端点与密钥继续由运行环境提供；面板离线模式无需密钥。

官方入口为 `webagent.official_agent:OfficialAgent`，默认读取 `code/harness/configs/official.yaml`。官方模型与浏览器由赛方提供；同一连接文件只启动一个客户端，待平台显示 `Agent connected` 后发起评测。连接认证代码完整保留，真实连接文件由启动参数指定。

回归命令：

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m pytest code\harness\tests -q
uv pip check --python .venv/Scripts/python.exe
```
