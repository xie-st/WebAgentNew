## 二、验收前准备

### 工程与接入

- [ ] 最终工程能按运行说明安装、导入、启动；相关回归结果与冻结版本一致。
- [ ] 官方入口和真实端入口分别经过实际运行验证，配置中的开关确实影响实际工具、输入与行为。
- [ ] 官方端只通过平台统一模型接口调用；真实端已核对赛方提供的模型标识与凭据，实际使用统一模型。
- [ ] 最终连接文件对应最终服务器与本队账号；同令牌旧客户端已停止，同队无其他在途官方任务。
- [ ] 官方端保持一次请求一个动作、使用当前观察元素编号，不暴露多Tab或平台不支持的模型参数。
- [ ] 提前截止保持关闭，实际配置 `deadline_margin_seconds: 0`；绝对deadline仍生效。
- [ ] 真实端可见浏览器、登录态、截图保存、暂停／继续／取消均已排练，登录与验证后会重新观察。
- [ ] 串行与并行两个配置均已验证；首版独立只读分支并行、共享写串行，所有分支共用限流和根预算。
- [ ] 日志、截图、结果文件可写、可打开；磁盘空间足够。

### 材料与设备

- [ ] 可运行工程、安装与启动说明、依赖清单、非敏感配置副本齐全。
- [ ] 3–5页方案报告完成，覆盖并行、结果确认、容错、频率控制及其取舍，效果主张均能找到对应证据。
- [ ] 已选机制的实验、独立回归、官方联调与真实网站记录已归档；未选候选不列为已实现能力。
- [ ] 本队账号可现场提供；密码、API Key、连接令牌及浏览器登录资料单独保管，不进入共享材料。
- [ ] 视频会议、麦克风、网络和屏幕共享可用；页面与日志文字清晰，敏感配置窗口不出现在共享画面。
- [ ] 浏览器、终端、平台记录页与汇报材料可快速切换。

阶段能力逐项核对仍使用[第二阶段验收要求](../06_分阶段实施/阶段二_基础能力与测试环境/03_验收要求.md)，实验与最终交付核对使用[第三阶段验收要求](../06_分阶段实施/阶段三_实验验证/03_验收要求.md)。此处集中记录现场准备情况。

每次运行至少可查：操作时间、目标页面、动作类型、结果、模型调用量。另关联任务、观察、动作、模型请求、截图与最终结果；真实并行补分支与Tab归属，接管补暂停／继续时间。

| 指标 | 汇总口径 |
| --- | --- |
| 完成情况 | 官方全部10项逐项列出；真实任务按完成条件与逐对象证据单列 |
| 时间 | 官方保存平台原始用时；自测同时记录总耗时、人工区间及扣除后的有效耗时，重叠人工区间只扣一次 |
| 操作量 | 页面访问、网页动作、失败／重复动作及核验动作按日志统计 |
| 模型消耗 | 平台受理调用、本地尝试和失败分别统计；规划、分支、核验、恢复及被弃用调用均计入 |
| token与费用 | 输入／输出token注明平台实测或本地估算；费用未知写未知，不把缺失值当0 |
| 并行效果 | 汇总共同成功任务的成对耗时、完成质量和全部分支成本，保留退化项 |

## 附：当前启动入口备查

下列命令依据现有代码核对，供准备运行说明使用；最终验收前用冻结版本复验，并把实际命令写入第一节。占位路径须替换为实际文件。

真实端环境自检，在项目根目录执行（不调用模型、不启动浏览器）：

```powershell
.\.venv\Scripts\python.exe -m webagent doctor --config code\harness\configs\real.yaml
```

官方连接，在 `D:\Dwen\Alpha26fall\WebAgentNew\code\official_client` 执行：

```powershell
..\..\.venv\Scripts\python.exe -m third_party_agent connect `
  --connection-file "<最终连接文件绝对路径>" `
  --agent webagent.official_agent:OfficialAgent
```

当前真实端单任务入口，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m webagent run `
  --config code\harness\configs\real.yaml `
  --backend playwright `
  --task-file "<现场任务JSON绝对路径>" `
  --run-id "<本次唯一run_id>"
```

任务JSON使用当前入口支持的任务条件字段，至少包含 `task`，按需包含 `start_url`；不嵌入预写动作序列或答案。真实模型从配置指定的环境变量读取端点与密钥；不得使用离线 `--model-script` 作为现场能力证据。最终并行和接管操作说明须随实际集成版本补齐并复验。
