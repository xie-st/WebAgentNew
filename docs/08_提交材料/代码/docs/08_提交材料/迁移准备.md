工具默认排除虚拟环境、Git、缓存、node_modules、真实环境变量文件、连接文件、账号和浏览器登录资料。连接／登录代码完整复制；现有凭据保留在原位置，启动脚本接受连接文件绝对路径。经验／恢复等开关若在最终版本启用，另核对配置引用的外部经验库、快照或素材并纳入交付，不能只复制 YAML。
