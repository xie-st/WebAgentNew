## 实现要点

### 真实模型适配（B01）

`RealModel` 实现 EffGen `BaseModel` 的 `load/generate/generate_stream/count_tokens/get_context_length/unload`：

- 从配置中的环境变量名读取 `WEBAGENT_MODEL_BASE_URL` / `WEBAGENT_MODEL_API_KEY`，不把值写入对象 repr、日志或记录。`load()` 只校验环境变量并创建 `httpx.Client(trust_env=False)`，不发请求。
- 使用 OpenAI 兼容的 `/chat/completions` 文本接口；请求只有 `model`、一条 user `messages`，可选 `max_tokens`/`temperature`，不发送 `tools`、`tool_choice`、视觉或模型探测参数。工具解析仍由 EffGen 文本 ReAct 负责。
- 每次 HTTP 尝试（含重试）生成一条 `ModelCallRecord`：`request_id`、provider `x-request-id`、模型、端点（去 userinfo/query）、attempt/retries、HTTP 状态、耗时、usage、失败类别。provider 未返回 usage 时 `input_tokens/output_tokens/total_tokens=None`、`usage_source="missing"`；本地估算单独放 `estimated_*`。
- 408/409/425/429/5xx 和网络错误按 `max_retries` 重试；非重试 4xx 立即失败。错误只含状态码/异常类型，不回传响应体或密钥。
- `generate_stream` 是单块兼容实现；第一阶段配置非流式，不产生第二次请求。

### Playwright 后端（B02/B06）

- 默认 `headless=False`；测试显式传 headless。使用 `launch_persistent_context`，专用 profile 在 `runtime/browser_profiles/<run_id>/`，不读取用户日常浏览器资料。
- `observe()` 等待 `domcontentloaded/load/readyState=complete`，从当前渲染 DOM 生成 AX 风格文本和元素表。元素包含 role/name/value/state/href 与 CSS 路径；隐藏、`pointer-events:none`、视口内被遮挡、不可交互元素不进入当前可操作表。元素编号每次观察重新分配。
- 动作全部通过 Playwright 真实输入：`locator.click()`、聚焦后 `End` + `keyboard.type()`（不 clear）、`keyboard.press`、`mouse.wheel`、`goto/go_back/go_forward`。不使用 JS 点击事件绕过。
- `type` 不暗中清空；`submit=true` 才按 Enter。执行后重新观察，失败也返回带 `error` 反馈的新观察，不伪造成功。
- 每次观察通过 session `EvidenceStore` 保存当前视口 PNG；截图 `Artifact.metadata` 含当时的 `url/page_id/observation_id`，事件 `artifact_saved` 同步记录。
- `close()` 只关闭本后端的 context 与 Playwright driver，幂等；专用 profile 保留但不删除，不触碰其他浏览器。

### CLI 与暂停/继续（B04）

```text
python -m webagent doctor --config <配置>
python -m webagent run --config <配置> --backend playwright|browser-use --task-file <任务文件>
```

- `doctor` 只检查配置、导入、Chromium 路径线索、runtime 目录和环境变量名是否存在；不调用模型、不启动浏览器、不启动官方任务。输出只含变量名。
- `run` 从外部 JSON 任务文件读取 `task/start_url/draft_text/run_id/headless/max_seconds`；执行器不含题目到动作/答案映射。`draft_text` 只作为任务条件追加/替换，不选元素。
- `control.jsonl` 文件驱动 pause/resume/cancel，不启动键盘监听线程。CLI 只在两个动作之间读取命令。
- `pause` 仅在无在途动作时由 `Session.pause()` 接受，丢弃未消费提案；提示用户可接管。`resume` 先 `backend.observe()`，再 `Session.resume(新观察)`，旧元素编号与旧动作绑定失效；`EffGenLoopDriver.resume()` 向同一生成器送回明确“NOT EXECUTED”的结果和最新观察，不静默重放。`cancel` 记录取消并关闭生成器、浏览器、会话。
- Ctrl+C 映射为 cancel；暂停等待有 `--pause-timeout`。

## browser-use 试验结论

**可只复用浏览器层。** 0.11.0 的 `Browser` / `Page` / `Element` / `Mouse` 足以完成导航、渲染 DOM 观察、真实点击/输入、截图；不需要启动其规划 Agent，也不需要替换 EffGen 决策循环。共同后端接口已实现，同一夹具任务链 headless 通过。

但当前不适合作为默认完整后端：

1. **依赖冲突**：browser-use 0.11.0 固定 `aiohttp==3.12.15`，EffGen 1.3.0 要求 `aiohttp>=3.14.3`；`uv pip check` 明确失败。最新 0.13.14 固定 `mcp==2.1.1`，又与 EffGen 的 `mcp<2` 冲突。没有找到可干净联合解析的已测版本。
2. **默认扩展联网**：0.11.0 首次启动会尝试下载 uBlock/ClearURLs 等扩展；接入中显式关闭 `enable_default_extensions`。
3. **参数陷阱**：`Browser(timeout=...)` 在该版本会意外选择 cloud browser；实现不使用该参数。
4. **Windows 代理解析**：browser-use 构造 cloud client 时，httpx 对本机 `NO_PROXY` 形状报 `InvalidURL`；后端在创建/启动 browser 时局部传入 `trust_env=False` 规避。该 workaround 仅限试验后端。
5. **额外日志/编码噪声**：browser-use 日志较多，部分 emoji 在 GBK 控制台产生 logging 错误；CLI 已用 `backslashreplace` 避免中断，但输出仍比 Playwright 嘈杂。

结论：B03 浏览器层复用成立；完整后端保留需用户确认依赖与环境 workaround。**默认后端建议 Playwright。**

## 与方案一致性、范围偏差

- 复用 A1 协议、Session 与 A2 生成器；没有另写规划循环。Playwright 与 browser-use 共用 `Backend`、同一个观察器、同一个工具 schema。
- 动作由环境执行一次；`proposed/dispatched` 不带执行结果；模型只在收到真实观察后继续。
- 输入不清空、AX 编号随观察失效、暂停时丢弃未消费提案、恢复时重新观察，均符合实施说明第 3/7 节。
- 偏差 1：`EffGenLoopDriver.start()` 现在把首个观察附加到 EffGen 任务串。A2 首轮模型输入原本没有当前页面，模型无法合法选择初始编号；该改动只影响 harness 驱动，A2 回归与上游测试均通过。
- 偏差 2：`real` 可选组只含 Playwright；browser-use 单列 `browser-use` 组，因为两者与 EffGen 无法联合解析。项目 .venv 仍按 B03 要求安装了 browser-use，但依赖检查失败已记录。
- 偏差 3：首次 browser-use 启动触发默认扩展下载尝试；已关闭默认扩展，后续验收运行无公网请求。
- 未扩大改造到官方 SDK、真实模型服务、公网页面或平台连接。
