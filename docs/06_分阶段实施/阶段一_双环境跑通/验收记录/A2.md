## 循环契约（实施后固定）

```python
step = driver.start()              # ACTION / COMPLETED / INCOMPLETE / DEADLINE / FORMAT_ERROR / ERROR / CANCELLED
action = driver.take_action()      # session.consume() 一次
result = backend.execute(action)   # 环境执行一次
step = driver.accept_observation(result.observation)
```

- 每次 `send` 前后是同一个 `Agent`、同一 thread；不重建 Agent。
- 请求先 `guard_requests`，再 `propose`；`take_action` 才 `consume`。`dispatched` 不是成功。
- 未消费的提案可 `session.pause()` 丢弃；暂停后 `resume(新观察)` 使旧编号失效。
- `before_step` 与 `before_model_call` 都调用 `session.check_deadline` 并记录模型调用。
- 默认 `max_iterations=None`：内部使用 `NO_ITERATION_CAP`，以 deadline 终止，不保留 10 步上限；显式传整数仍生效。
- 默认 `max_turns_without_progress=None`：正常多页浏览不会被“没有进展”催促截断。
- 生成器在请求处关闭时不写该调用的结果（无 ObservationStep、无 feedback）。
