# 第三阶段：实验验证

状态：范围草案，未审批。

以第二阶段可重复的基线为起点，一批只改一个机制，保留独立回归任务。比较观察筛选、历史表示、核验时机、恢复策略、skill、串并行执行及允许调整的推理配置。

每批先提交问题、假设、改动、任务、预算、指标和停止条件；用户批准后运行，再交回结果，由用户决定下一批。统计完整完成率、通过任务耗时、人工接管时间、网页操作、模型调用和 token；费用缺失时保留未知，不推算为官方值。

官方任务按赛方要求逐项运行。真实网站用同任务、同模型的串行与并行结果展示收益。保留原始日志，轨迹分析另存。实验结论用于最终配置、真实演示和3–5页报告。

进入本阶段前补齐详细方案、DSH 实施说明和验收要求，单独审批。本文不授权实验。
