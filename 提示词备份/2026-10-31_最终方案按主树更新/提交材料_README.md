## 提交前配置核对

以下项目全部检查完成、问题修复并复验后，才能将最终结论改为“已确认，可提交”。核对最终提交包解压后的实际文件，保留配置副本、命令、结果与截图。

- [ ] **版本与依赖**：记录代码版本及未提交差异；确认 Python、依赖、vendored EffGen、官方 SDK、Chromium 的版本和实际导入路径；按安装说明在交付目录成功安装、导入和启动。
- [ ] **全部配置文件**：逐份核对随包配置、示例环境变量及实际启动参数；确认配置可加载、无重复 YAML 键、占位值已处理、相对路径在交付目录有效，生效配置与说明一致。
- [ ] **真实端模型**：核对实际服务地址、模型标识、环境变量和鉴权；使用比赛要求的统一模型，执行一次真实调用。确认 demo 实际读取的配置文件，不以脚本模型结果代替真实模型验证。
- [ ] **官方端接入**：核对最终服务器、本队连接文件、SDK 与入口 `webagent.official_agent:OfficialAgent`；确认平台在线、单任务串行、一次交出一个动作，统一模型由官方接口提供。
- [ ] **开关与预算**：逐项确认状态、核验、恢复、上下文、经验和并行开关的最终值及实际行为；官方端并行关闭，`deadline_margin_seconds: 0`；核对任务时限、输入预算、消息数、请求大小、并发与限流。
- [ ] **demo 运行**：核对启动命令、端口、网址、可见浏览器、运行目录及写入权限；验证任务输入、日志、回答、截图、暂停／继续／取消和证据下载，按 D01–D20 留下验收记录。
- [ ] **自验证结果**：在冻结版本执行回归与 demo 验收，保存实际命令、通过／失败数量、run_id、日志和真实截图；区分离线测试、真实模型运行及官方成绩，截图可追溯至同次运行。
- [ ] **打包与材料**：在提交包中复跑启动流程；PPT 可打开，截图清晰，材料路径和版本一致；检查代码、配置、日志及截图中的凭据，真实密钥、连接令牌与浏览器登录资料不进入共享包。
