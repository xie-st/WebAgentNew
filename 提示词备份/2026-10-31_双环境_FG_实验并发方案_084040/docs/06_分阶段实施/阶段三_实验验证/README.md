# 第三阶段：实验验证

状态：2026-10-31实验效率修订已按用户要求纳入方案；具体批次仍逐批审批。进入条件为第二阶段完成验收与交接，当前缺项以[验收复核](../验收复核_20261031.md)及后续关闭记录为准；本文不表示第三阶段已开始。

以第二阶段可重复的基线为起点：P0冻结并取得当前官方基线；P1本地逐层筛选、有依据的候选尽早进入官方单项对照；P2组合与独立回归；P3最终双环境复验与交付。每批只验证一个问题，复用EffGen原生入口和既有测试环境。

官方效果方向先考虑核验时机、停滞恢复；后续按最新失败轨迹、输入与耗时证据，在折叠、摘要、筛选等候选中滚动选择，不固定跑完一条序列。真实端串行／2分支单独安排，首版限独立只读任务、共享写串行，不占官方实验的固定第三位；截图与推理配置须先满足接口条件。附加A–F继续备选。

采用“DSH并行准备→单人集成并冻结→本地筛选→官方串行验证”的流水线。官方测试当前冻结版本时，可继续已批准的独立实现、离线验证与既有训练轨迹分析；测试版本及运行资源保持稳定。真实模型计时对照顺序运行，官方始终单在途，按平台实际支持的论坛／电商批次启动，不假定能任意抽选单题。三层评测用途保持，暂不另行部署WebArena。
