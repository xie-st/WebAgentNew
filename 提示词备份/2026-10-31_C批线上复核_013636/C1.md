## 实现要点

### C01 官方模型

`OfficialModel` 实现 EffGen `BaseModel` 的 `load/generate/generate_stream/count_tokens/get_context_length/unload`：

- `generate` 只向 SDK 传一个位置参数 `messages`；每条消息仅含字符串 `role` 和 `content`，角色限定 `system/user/assistant`，拒绝 tool role、图像内容、额外字段。
- EffGen 的完整平铺提示作为一条 user 消息；显式提供的 system prompt 保持 system 角色；也支持直接传入 role/content 消息列表用于契约核验。
- 不读取或转发 `GenerationConfig` 的 temperature/top_p/max_tokens，不传模型名、tools、tool_choice、图片或推理参数。
- SDK 只返回 `.text` 和 `.request_id`，没有精确 usage：`OfficialCallRecord` 与 `model_call` 事件的 `input_tokens/output_tokens/total_tokens` 均为 `None`，`usage_source="missing"`；本地估算单独放 `estimated_input_tokens/estimated_output_tokens`。
- 每个实际调用（包括 SDK 抛错后调用方再次请求）都生成一条记录并触发一次 `model_call`；不自动重试，符合冻结 SDK“失败不自动重复请求供应商”的说明。记录 `request_id`（平台返回时）与调用序号。
- `GenerationResult.tokens_used` 以 0 满足 EffGen 的 int 类型，但 metadata 明确 `token_count_source="platform_usage_unavailable"`、精确 token 为 null，估算另列。

### C02 官方动作与 AX 编号

- 动作严格按 README：`click [id]`、`type [id] [text] [0|1]`、`press [keys]`、`scroll [down|up]`、`goto [url]`、`go_back`、`go_forward`、`stop [说明]`。
- 文本用反斜杠线格式转义：`\\`、`\[`、`\]`、`\n`、`\r`、`\t`，避免 `]` 或换行截断动作；中文与圆括号原样保留。孤立代理项、未支持控制字符、含括号/空白/控制字符的 goto URL 显式报错，不静默破坏结构。
- AX 元素编号只从 `observation.text` 的行首 `[数字]` 解析；DOM 的 `nodeId`/`backendNodeId` 不进入元素表，也不能成为动作编号。
- 动作校验完整 `(run_id, page_id, observation_id, AX 编号)`；目标必须属于当前元素表。`goto` 还要求 URL 是本任务已观察到的、与当前页面同源的确切 URL；本进程从不打开该 URL。
- 旧观察动作、错误页面/运行、未知 AX 编号均在序列化前拒绝。

### C03 官方观察与原件

- 默认 AX 来自 `observation.text`；HTML、DOM、截图字段缺失时仍能生成可决策观察（元素表来自 AX）。
- DOM 直接读 `observation.dom.root`，不调用 `get_dom`；序列化后写入证据目录并计算 SHA-256/大小。
- 截图元数据默认在每次观察时通过冻结 `browser.save_screenshot`（完整元数据时）或 `get_screenshot` 同步下载；HTML 默认按需通过 `get_html` 下载（例如模型调用 `evidence_save`）。下载都在当前 SDK 回调内完成并检查剩余预算。
- 两种原件都核对字节数与 SHA-256；PNG 另核对签名、IHDR 尺寸；HTML 按 UTF-8 字节核对。失败返回 unavailable artifact，并写 `artifact_error` 事件（kind/reason/message），不引用旧文件、不冒充成功。
- `unavailable`、`size_limit`、`capture_failed`、`missing_*`、`invalid_metadata`、`integrity_mismatch` 等原因保留在 `Artifact.reason`。每帧重新构造 ArtifactSet；上一帧的截图/HTML/DOM 不会因本帧缺字段而沿用。
- 下载成功的原件写入 `runtime/runs/<local_run_id>/screenshots|html|dom/`；`evidence_save` 可按需加载尚未下载的 HTML/截图，并复用同一完整性校验。

### 官方 Agent 驱动

`OfficialAgent.reset/step/close` 遵循阶段一驱动顺序：

- `reset` 只记录平台 run id、关闭旧任务并建立空容器；不假定 reset 含 task/observation。
- 首次 `step` 读取完整 task、当前观察与 `execution_deadline`，创建 Session、OfficialBackend、OfficialModel 与一个 EffGen 驱动/生成器。
- 生成器内部工具继续直行；遇到网页请求时经 A1 `guard_requests`/`session.propose` 校验，`serialize_action` 成功后才 `take_action` 并返回一个动作。
- 后续 `step` 用当前请求建立新观察，关联上一动作，以 `observed` 反馈送回同一生成器，再返回一个动作。
- 生成器结束转成 `stop [说明]`；`DriverStatus.COMPLETED` 只表示本地结束，不写官方分数。`AgentResponse.success` 不作为通过成绩。
- deadline 已过时在本地工作前停止，返回 stop；模型、下载与动作都不再产生。`close` 幂等。
- 官方 run id 若不符合本地目录字符规则，会转为确定性的 `official-<sha256前40位>` 本地 run id；`platform_run_id` 仍保留原值，供主线程关联平台记录。

## 范围偏差、限制与待核实

1. **动作转义约定**：冻结 README 只规定括号结构，未定义服务端 unescape。C1 采用反斜杠线格式（`\\`、`\[`、`\]`、`\n`、`\r`、`\t`），保证动作不被截断，并用 round-trip 测试验证；实际平台是否按同一约定还原文本，需 C05 真实任务观察。若平台把转义当字面字符，需在主线程获知后调整输入策略。这是本批最需要真实验证的一项。
2. **截图下载策略**：`OfficialAgent` 默认对每帧存在的 screenshot 元数据同步下载并核验，作为本地证据；HTML 默认按需（`evidence_save`/`download_artifact`）。如主线程希望截图也完全懒加载，可把 `download_artifacts` 设为空集；C1 未改 `official.yaml`。
3. **反馈状态**：平台 step 请求没有显式“动作成功”字段时，C1 记为 `observed`（收到新观察），不写成业务成功；若请求带 `action_error`/`error`，记为 `error`。官方动作是否实际生效仍以平台最终判分为准。
4. **精确 usage**：SDK 不返回 token 用量；事件中为 null，估算另列。EffGen 的 `GenerationResult.tokens_used` 只能为整数，C1 置 0 并在 metadata 标明来源，不能当作精确值。
5. **新增事件/桥接参数**：`artifact_error` 与 `artifact_loader` 是对 A1/A2 harness 的增量改动；未改变既有事件必需字段或默认调用行为，A1/A2/B1 回归通过。
6. **C1 离线阶段未执行真实连接/评分**；C04-C08 已由主线程于 2026-10-31 完成并验收（见上表），其中 task 731/605 因连接中断按 deadline 判 0，未复跑。

- 复用冻结 `third_party_agent` 的 model/browser 模块，未修改其 model/session/outbound 源码。
